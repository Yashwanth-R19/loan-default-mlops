Dataset

Source
Kaggle — Loan Default Prediction
Rows × columns
255,347 × 18
Target
Default (binary)
Class balance
11.6% positive
Training subsample
50,000 rows, stratified 80/20 split

Eighteen raw columns cover applicant demographics, loan terms, and existing financial obligations. Numeric features are standardized and categorical features one-hot encoded inside the same scikit-learn Pipeline that's saved and served, so training-time and inference-time preprocessing can never drift apart.

All three models were tuned with Optuna (25 trials, 3-fold stratified CV) and ranked on ROC-AUC. Precision is low across the board because of the class imbalance and the deliberate choice to optimize ROC-AUC — keeping recall (catching actual defaults) reasonably high — rather than accuracy. See the repository's SHAP summary plot for feature-level explainability of the winning model.
